# 0.5.0 — 2026-11-21

## Added

- **Bill vote metadata** in `openstates_get_bill` and `openstates_search_bills` includes the voting organization's recorded ID, name, and classification, plus the recorded motion classifications ([#56](https://github.com/cyanheads/openstates-mcp-server/issues/56)).
- **Event agenda references** in `openstates_get_event` and `openstates_search_events` retain names and types alongside supplied bill, organization, person, and vote IDs. Linked bills can include identifier and session, and linked organizations can include classification ([#57](https://github.com/cyanheads/openstates-mcp-server/issues/57)).

## Changed

- **Runtime requirement** is Bun 1.4.4 or newer.
- **Deployment configuration** validates `MCP_HTTP_ENDPOINT_PATH` and `MCP_PUBLIC_URL` at startup. Relative `LOGS_DIR` paths resolve from the server package root. Filesystem storage copies existing data into `_v2/` on first start and retains the original directories.
- **Jurisdiction resources** explicitly retain the listed title `Jurisdiction Metadata` with the updated framework.
- **Rate-limit errors** render the retry delay in the text response when Open States supplies one.
- **MCPB packaging** excludes dependency agent docs and build-only files.

## Removed

- Upstream HTTP errors no longer expose the captured response in `structuredContent.error.data.body` or `structuredContent.error.data.responseBody`.

## Fixed

- **Open States links** with only a URL now pass output validation across bill, committee, event, and people tools. For HTTP(S) links without a nonempty note, the formatter uses the URL as the label ([#61](https://github.com/cyanheads/openstates-mcp-server/issues/61)).
