# 0.3.1 — 2026-08-24

## Added

- **MCP 2026-07-28** is supported alongside 2025-era clients through the framework's SDK v2 protocol stack.
- **Public cache hints** advertise one-hour reuse for tool, prompt, resource, and discovery catalogs, plus 12-hour reuse for jurisdiction resources.

## Changed

- **Tool input schemas** reject undeclared root keys, matching the strict contracts advertised to clients.
- **Tool output schemas** advertise the structured error envelope that handlers already return on failures.
- **`MCP_SESSION_MODE`** is explicitly `stateless` in the container, `.env.example`, and README; the documented `auto` schema default resolves to stateful.
- **Framework tooling** aligns handlers, tests, container packaging, and agent skills with `@cyanheads/mcp-ts-core` 0.12.3 and Bun 1.4.0.
- **Package metadata** classifies the Codex plugin under Government Data and routes private vulnerability reports to `security@caseyjhand.com`.
