# 0.1.15 — 2026-07-26

## Added

- **`OPENSTATES_DAILY_REQUEST_BUDGET`** — the daily request-budget guard's cap is now configurable (default `250`, the free-tier daily cap) instead of hardcoded; the budget-exceeded message now names itself as a self-imposed cap and points at the env var. ([#28](https://github.com/cyanheads/openstates-mcp-server/issues/28))
- **`OPENSTATES_REQUEST_TIMEOUT_MS`** — the per-attempt upstream deadline is now configurable (default `45000`, min `1000`) instead of a fixed 15s ceiling that rejected scoped queries upstream could still answer. ([#29](https://github.com/cyanheads/openstates-mcp-server/issues/29))
- **`upstream_timeout` error contract** — every tool and the `openstates://jurisdiction/{id}` resource now declares a typed `upstream_timeout` reason with a recovery hint scoped to that call's own broadening levers, instead of the request hanging with no actionable guidance. ([#25](https://github.com/cyanheads/openstates-mcp-server/issues/25))
- **`jurisdiction_required` error contract** — `openstates_search_people` and `openstates_search_committees` now reject an omitted `jurisdiction` before issuing a request, since an unscoped search exceeds the upstream timeout rather than returning a large result set. ([#26](https://github.com/cyanheads/openstates-mcp-server/issues/26))
- **`openstates_search_bills`** — sponsorships carry a linked `person` record (OCD person ID + name) when the sponsor resolves to a known legislator; results also carry `openstates_url` and `updated_at`. ([#27](https://github.com/cyanheads/openstates-mcp-server/issues/27))
- **`openstates_get_bill`** — output carries `updated_at`. ([#27](https://github.com/cyanheads/openstates-mcp-server/issues/27))
- **`openstates_search_people`** / **`openstates_get_legislators_by_location`** — person records carry `image` (official headshot URL) and `current_role.division_id` (OCD division) when upstream publishes them. ([#27](https://github.com/cyanheads/openstates-mcp-server/issues/27))

## Changed

- **`openstates_search_bills` / `openstates_search_people` descriptions** — corrected to state that a `q`-only or name-only search spanning all 56 jurisdictions exceeds the upstream timeout, replacing the earlier "may return a large result set" framing. ([#26](https://github.com/cyanheads/openstates-mcp-server/issues/26))

## Fixed

- **Upstream timeout amplification** — `OpenStatesApiService` now arms a caller-owned deadline composed with `ctx.signal` and re-stamps an expired deadline (or a `504`/`408`/`425` status) as non-retryable `upstream_timeout` before `withRetry` spends the remaining shared-key budget on a doomed request. Measured: 72.5s across 4 attempts before the fix, one attempt after. ([#25](https://github.com/cyanheads/openstates-mcp-server/issues/25))
