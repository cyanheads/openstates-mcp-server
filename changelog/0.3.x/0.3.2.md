# 0.3.2 — 2026-09-20

## Added

- **`teardown()`** releases the Open States service's daily-budget rate limiter and clears its singleton on every shutdown, wired through `createApp({ teardown })`.

## Changed

- **`sessionMode: 'stateless'`** is now declared explicitly in `src/index.ts` via `createApp()`, instead of leaving HTTP session posture to `MCP_SESSION_MODE`'s schema default (`auto`, which resolves to stateful). The resolved mode is published on the server card under `_meta` key `io.github.cyanheads.mcp-ts-core/sessionMode`.
- **Argument rejections** now classify `InvalidParams` (-32602) instead of `ValidationError` (-32007), carrying `data.reason: "invalid_arguments"` and a schema-derived recovery hint. Breaking for a client matching on the prior code.
- **Tool error text** (`content[0].text`) now carries a `Recovery: <hint>` line and closes with a `(reason <reason>)` marker — neither appeared before.
- **`error.data`** on a tool error no longer includes the upstream request URL.
- **A caller disconnecting mid-call** now classifies `RequestCancelled` (-32011) instead of an internal error; an upstream `500` is now retried instead of failing on the first attempt.
- Agent skill tree moved from `skills/` to `framework-skills/` — Claude Code and Codex auto-load a plugin's root `skills/`, so that name stays free for skills meant for installing agents.
