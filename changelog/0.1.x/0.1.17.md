# 0.1.17 — 2026-07-31

## Added

- **`OPENSTATES_TOTAL_REQUEST_BUDGET_MS`** — wall-clock ceiling in milliseconds for one call across every retry attempt and the backoff between them, bounding a slow-but-retryable upstream that would otherwise run the full four-attempt ladder (previously up to ~190s). Default `90000`, minimum `1000`; startup rejects a value below `OPENSTATES_REQUEST_TIMEOUT_MS`. ([#34](https://github.com/cyanheads/openstates-mcp-server/issues/34))
- **`invalid_page`** error contract on `openstates_search_bills`, `openstates_search_people`, `openstates_search_committees`, `openstates_search_events`, and `openstates_list_jurisdictions` — a page past the last one now returns `data.reason: "invalid_page"` and a recovery hint instead of a bare, unclassified 404. ([#33](https://github.com/cyanheads/openstates-mcp-server/issues/33))

## Changed

- **Upstream error messages** now carry the `detail` string Open States returns on every 4xx (e.g. `Open States rejected the request: invalid page, must be in [1, 1].`) instead of the generic transport failure that read like the endpoint was missing. Scoped to 4xx responses with a parseable string `detail`. ([#33](https://github.com/cyanheads/openstates-mcp-server/issues/33))
- **Error URLs** in thrown errors and debug logs are now redacted to origin + path, dropping the query string.

## Fixed

- **`openstates_get_legislators_by_location`, `openstates_search_people`, `openstates_search_committees`, `openstates_get_committee`, `openstates_search_events`, `openstates_get_event`** — link, media, and document lists no longer render a dangling `: ` before the URL when the upstream `note` field is empty. `structuredContent` is unaffected. ([#37](https://github.com/cyanheads/openstates-mcp-server/issues/37))
