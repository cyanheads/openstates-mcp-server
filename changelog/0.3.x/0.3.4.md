# 0.3.4 — 2026-10-25

## Changed

- **Framework error rendering and validation:** tool errors escape Markdown punctuation while structured error messages retain literal text; invalid startup configuration names its environment variable (0.13.16), and prompt requests without arguments report missing required fields (0.13.15).
- **Packaging:** MCPB bundles exclude source, scripts, documentation, and editor/CI configuration; the Docker image uses the hyphenated server name as its display title.
- **Maintenance templates:** synchronize framework skills and security-audit classification, document request-state signing, SSE replay, and interaction logging configuration, and refresh the README overview and badges.
