# 0.4.0 — 2026-10-28

## Added

- **`skill://openstates-guide/SKILL.md` resource** — the `openstates-guide` agent skill served over MCP through `createApp({ skills })` (`resources/list` gains it and `resources/templates/list` the `skill://{+path}` template), and shipped under `skills/` in the npm package, Docker image, and `.mcpb`.
- **Agent Plugins manifests** — root `plugin.json` and `mcp.json`.

## Changed

- **`rate_limited` errors** on every tool and the jurisdiction resource (#51) — an Open States 429 or the server's own `OPENSTATES_DAILY_REQUEST_BUDGET` now carries Open States' `detail`, `retryable: true`, and `retryAfter` seconds (`Retry-After` when sent, else the time to the next UTC minute, hour, or day boundary the `detail` names). The call stays one attempt.
- **`openstates://jurisdiction/{+jurisdiction_id}`** (#48) — the template accepts the slash-delimited OCD ID as `openstates_list_jurisdictions` returns it, plus multi-word state names; percent-encoded values are decoded once and a malformed escape is a validation error.
- **`openstates_search_events`** (#60) — an empty result from `require_bills`, `after`, or `before` names those filters and suggests widening them, rather than blaming missing state data.
- **`openstates_legislator_profile` prompt** — sponsored-bill and committee steps point at the legislator's `ocd-person` ID.
- **Framework sync** — mcp-ts-core 0.13.18 framework skills (new `add-skill`), tooling, a stricter `lint:packaging`, `.mcpbignore`, and the single-table bug-report template; `bunfig.toml` `minimumReleaseAge` 3 days → 1 day.

## Fixed

- **Markdown rendering of upstream strings** (#53) — every tool's `content[]` escapes upstream text and renders URL and image fields as links and images, so a CommonMark parse reads back what `structuredContent` carries.
- **`openstates_search_events` / `openstates_get_event` `media[]` and `documents[]`** (#59) — items follow the upstream `note`, `date`, `classification`, and `links[]` shape (`media` adds `offset`); events carrying them no longer fail output validation.
- **`openstates_search_people` `org_classification: "legislature"`** (#55) — returns the members of unicameral bodies (Nebraska, DC); bicameral states keep the `upper` + `lower` union.
- **`openstates_get_bill` `openstates_id`** (#49) — rejected with `invalid_openstates_id`, before any request, unless it is `ocd-bill/<uuid>` or a `<jurisdiction>/<session>/<bill_id>` path (`ocd-bill/`, a bare UUID, and `ocd-bill/not-a-uuid` are rejected); the `not_found` recovery now covers direct-ID lookups.
- **`.`, `..`, and empty IDs** (#58) — `openstates_get_jurisdiction`, `openstates_get_committee`, `openstates_get_event`, and each part of the `openstates_get_bill` path lookup fail with a validation error before any request.
