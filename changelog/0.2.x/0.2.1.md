# 0.2.1 — 2026-07-31

## Changed

- **`openstates_search_people`** description, README, `docs/design.md`, and `docs/idea.md` no longer advertise a `party` filter — upstream `/people` has no such parameter. `party` is still reported on every result; only the filter claim is withdrawn. ([#39](https://github.com/cyanheads/openstates-mcp-server/issues/39))

## Fixed

- **`openstates_get_bill`, `openstates_search_bills`** — bill abstracts, versions, documents, vote headings, and action lines no longer render an empty upstream `note`, `date`, or `start_date` as orphaned punctuation (`_()_`, a bare `()`, a doubled space, an orphan colon). `structuredContent` is unchanged — the empty string is still the accurate upstream value. ([#38](https://github.com/cyanheads/openstates-mcp-server/issues/38), [#41](https://github.com/cyanheads/openstates-mcp-server/issues/41), [#43](https://github.com/cyanheads/openstates-mcp-server/issues/43))
- **`openstates_get_jurisdiction`, `openstates_list_jurisdictions`** — legislative session lines no longer render an empty `classification` as a bare `()`; a missing `start_date`/`end_date` endpoint renders as `from <date>` or `until <date>` instead of a dangling separator, since every observed gap belongs to a session that already concluded. ([#43](https://github.com/cyanheads/openstates-mcp-server/issues/43))
- Test files mocking `openstates-service.ts` now spread the real module via `importOriginal` instead of replacing it outright, so a future export from the service no longer breaks unrelated tests with an undefined-symbol error. ([#40](https://github.com/cyanheads/openstates-mcp-server/issues/40))
