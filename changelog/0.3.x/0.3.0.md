# 0.3.0 — 2026-07-31

## Changed

- **`openstates_search_bills`** — a call omitting both `jurisdiction` and `q` now fails input validation instead of returning a typed tool error. The `missing_scope` `errors[]` entry, its `-32007` code, `structuredContent.error`, `data.reason`, and `data.recovery.hint` are gone; the rejection is a schema issue whose message carries the same recovery guidance. `jurisdiction` and `q` both gain `.min(1)`. ([#45](https://github.com/cyanheads/openstates-mcp-server/issues/45))
- **`openstates_search_people`** — the `jurisdiction`-or-`id` refinement message now states the recovery guidance directly, instead of naming only the two fields.

## Fixed

- **`openstates_search_bills`, `openstates_search_people`** — an empty-string `jurisdiction` (or `q`) now rejects identically on both tools instead of splitting between a schema `too_small` error on one and a typed tool error on the other. ([#47](https://github.com/cyanheads/openstates-mcp-server/issues/47))
