# 0.1.10 — 2026-06-21

## Added

- **`appliedFilters` enrichment** — `openstates_search_bills`, `openstates_search_people`, `openstates_search_events`, and `openstates_search_committees` now echo the filters the server received in a typed `enrichment.appliedFilters` field, present on both the empty-result and success branches, with an `enrichmentTrailer.render` so it reaches `content[]`. Lets an agent confirm its parameters transmitted before concluding a zero-result query is genuine. ([#10](https://github.com/cyanheads/openstates-mcp-server/issues/10))
- **ISO 8601 date validation** — `action_since`/`updated_since` (`openstates_search_bills`) and `after`/`before` (`openstates_search_events`) gain a loose ISO 8601 `.regex()` (date-only or datetime) that surfaces as JSON Schema `pattern`, rejecting malformed dates like `"yesterday"` or `"05/30/2026"` before they reach the Open States API and silently return zero results. ([#12](https://github.com/cyanheads/openstates-mcp-server/issues/12))
